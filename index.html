Install in 3 steps

  1. Download the app with the button above. If the phone asks, tap Download or Keep.
  2. Allow the install. Tap the downloaded file. If Android says it blocked the install, tap Settings and turn on Allow from this source (also called Install unknown apps) for the app you downloaded with, such as Chrome. Then go back.
  3. Tap Install. If Google Play Protect warns about an unknown app, tap More details, then Install anyway. This is normal: the app is not on the Play Store.

Then open Fabros Companion and sign in with the account the clinic made for you.

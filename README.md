# Fabros Companion (Android)

The full name of the app is **Fabros Patient Companion App**. On the phone it is called **Fabros Companion** and has a teal icon with a white **F**.

Parent app of Fabros Children's Clinic. This is a **test build** that uses the clinic's sample (TEST) data.

## Install

Scan this code with the phone's camera, or open the link on the phone:

![QR code for the download link](fabros-install-qr.png)

<https://github.com/breerivera/fabros-patient-app-releases/releases/latest/download/FabrosCompanion.apk>

The link always gives the newest version, so the QR code never changes.

1. Open the link (or scan the code). The phone downloads `FabrosCompanion.apk`. If it asks, tap **Download** / **Keep**.
2. Tap the downloaded file to open it.
3. If Android says it blocked the install, tap **Settings** and turn on **Allow from this source** (also called **Install unknown apps**) for the app you downloaded with (Chrome, Camera, Files). Go back and tap **Install**.
4. If **Google Play Protect** says "App blocked" or "Unknown developer", tap **More details**, then **Install anyway**. The app is not on the Play Store, so this warning is normal.
5. Open **Fabros Companion** (the teal icon with a white F) and sign in with the account the clinic made for you.

## Notes

- Needs Android 7.0 or newer.
- A new account can only be used on one phone. If the app says the account is registered on another phone, ask the clinic to revoke and release it.
- Later versions install over this one without losing anything, as long as they are signed with the same key.
